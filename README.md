# Neighborhood Connect

This repo is a pnpm + Turborepo monorepo for web, API, and shared packages.

## Requirements

- Node.js 18+
- pnpm 9+

## Install

```
pnpm install
```

## Common commands

```
pnpm dev
pnpm build
pnpm lint
pnpm test
```

## Repo layout

- `apps/web`: web app (stack to be chosen)
- `apps/api`: API service (stack to be chosen)
- `packages/types`: shared TypeScript types
