# Separate Cognito App Client for the Mobile App

The Web App authenticates through Cognito's Hosted UI, a browser-redirect OAuth flow that doesn't map cleanly onto a native app. The Mobile App will authenticate against the same Cognito User Pool (same users, same backend) but through its own **Mobile Auth Client** — a second Cognito App Client with a native redirect URI scheme (e.g. `neighborhoodconnect://callback`) and independent token/session lifetimes, accessed via an in-app browser session (e.g. `expo-auth-session`) rather than reusing the Web App's App Client. This is standard Cognito practice for multi-platform products and avoids the two platforms' redirect URIs and session lifetimes fighting each other, at the cost of one more piece of Cognito configuration to keep in sync with the user pool's shared settings.
